# Utilidades de Windows

Estos scripts no son necesarios para el uso normal de App Gastos. Para abrir la aplicación usá `start.bat` desde la raíz.

- `build_windows.bat`: compila el ejecutable con PyInstaller.
- `check_app.bat`: ejecuta el smoke test manualmente.
- `validate.bat`: compilación + pruebas unitarias.
- `install.bat`: fuerza la instalación de dependencias.
- `install_ocr.bat`: instala/actualiza el stack OCR.
- `run.bat`: abre la app sin repetir instalación preventiva.
