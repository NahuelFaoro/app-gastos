# Fuentes de iconos

El catálogo usa las fuentes distribuidas por qtawesome: Remix Icon y Phosphor. Las ilustraciones combinan relleno y contorno de esas fuentes con dibujos vectoriales locales y el color elegido por el usuario.

- Phosphor: https://github.com/phosphor-icons/core — MIT. Licencia: https://github.com/phosphor-icons/web/blob/master/LICENSE
- Los archivos de licencia de las fuentes se distribuyen dentro de qtawesome; no se descargan assets al ejecutar la app.
- La alcancía ilustrada es un dibujo local. En el modo Contorno usa una caja de ahorro del catálogo instalado.
